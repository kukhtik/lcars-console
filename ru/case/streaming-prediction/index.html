CASE 10 / picard

Streaming stateful prediction

Stateful-рекуррентная модель (GRU, пошаговый экспорт в ONNX) со строгим контрактом состояния: инференс по одной строке, hidden state переносится между вызовами. Ключевое — метрико-выровненный лосс: реализация официальног

4–5×сигнал на полном окне
1.38×запас in-graph фич
500kстрок в проверке документации

Задача

Модель должна предсказывать цель по одной строке за раз в потоке: каждая строка зависит от всей предыдущей истории, окно — десятки тысяч строк, а метрика считается блоками внутри последовательности (корреляция, а не MSE). Обычные рецепты (нарезка окнами, MSE-лосс) здесь не работают.

Подход

Stateful-рекуррентная модель (GRU, пошаговый экспорт в ONNX) со строгим контрактом состояния: инференс по одной строке, hidden state переносится между вызовами. Ключевое — метрико-выровненный лосс: реализация официального блочного агрегата на torch, побитово сверенная со скорером, и корреляция, накапливаемая по всей последовательности (а не по короткому окну, где цель почти постоянна и сигнал тонет в шуме).
